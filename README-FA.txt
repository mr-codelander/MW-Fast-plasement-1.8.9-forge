Fast Place - Minecraft Java 1.8.9 Forge

1) Java 8 JDK را نصب کن.
2) این پوشه را Extract کن.
3) روی build.bat دوبار کلیک کن.
4) فایل مود بعد از Build در build\libs ساخته می‌شود.

مود:
- Minecraft Java 1.8.9 + Forge
- کلید پیش‌فرض B
- قابل تغییر از Options > Controls
- نگه داشتن راست‌کلیک برای Place سریع
- نمایش FastPlace: ON/OFF در گوشه صفحه
- فقط تأخیر سمت کلاینت را حذف می‌کند؛ محدودیت سرور همچنان می‌تواند اعمال شود.

اگر چند Java نصب داری، JAVA_HOME را به پوشه JDK 8 تنظیم کن.
